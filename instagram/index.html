Instagram kit

REFILLSpecialty Coffee

A profile picture and eight highlight covers, all drawn on the measured geometry of the Refill cup-arch: same stroke, same proportions, brand colours only. Several icons borrow from the interior itself, such as the arched door with its porthole and the olive planting.

Profile picture

The arch alone, which stays legible at Instagram's smallest size. It is optically centred (lifted 1.2%, because the round bottom reads heavier) and sized to clear the circle crop.

Highlight covers

The covers follow the guideline's structure. There is no text inside the circles, because Instagram already prints the label underneath. Each cover is 1080 x 1920, so it can be posted as a story and set as the cover.

Plaster

Recommended. Espresso line icons on Plaster: calm, and it contrasts with the dark profile picture.

Espresso

Plaster on Espresso: a bold, dark row.

Tonal

Each cover takes a palette colour, so the row reads as a ramp from plaster to espresso.

The icon set

Drawn on a 100-unit grid with a 5.2-unit stroke, the same stroke-to-width ratio as the logo. Flat ends and sharp corners match the arch. They're delivered as SVG, so they can go on the website, menus and wayfinding too.

Setting it up

Profile picture

Upload profile-espresso-1080.png. Instagram crops it to a circle; the arch is already sized for that.

Covers

Post each cover PNG to your story, add it to its highlight, then choose Edit highlight, Edit cover, and select it.

Order

Location, Menu, Best sellers, About Refill, Beans, Seasonal, Reviews, Events. Most-tapped first.
